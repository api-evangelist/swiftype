# Swiftype (Elastic Site Search)

> Swiftype is a hosted site-search and app-search platform, now operated by Elastic as Elastic Site Search. Its Site Search API lets you index documents, crawl domains, run relevance-tuned search and autocomplete, and pull query/click analytics over a REST API at https://search-api.swiftype.com/api/v1/. Authentication is via a private auth_token (full access) or a public engine_key (read-only client-side search). This llms.txt is generated by the API Evangelist enrichment pipeline from the provider's public documentation.
